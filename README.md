# 快捷键管理器 V2 (Hotkey Manager V2)

这是一个基于 AutoHotkey v2 和 gemini 和许多头发，开发的轻量级、功能强大的快捷键管理工具。它允许您为单个按键或组合键配置多种动作，并支持点击次数检测（如双击、三击）。

## ✨ 主要功能 (Features)

- **多重动作支持**：一个快捷键可以按顺序执行多个动作（运行程序、打开网址、执行 CMD 命令、发送按键）。
- **点击次数检测**：支持单击、双击、三击甚至更多次数的触发逻辑。
- **组合键支持**：支持标准组合键（如 `Ctrl + Alt + A`）以及特殊硬件扫描码（如 `SC10A`）。
- **可视化配置**：直观的 GUI 界面，支持按键捕获、动作编辑和参数调整。
- **开机自启**：内置开机自动启动选项。
- **多语言支持**：支持实时切换中文/英文界面。
- **托盘管理**：最小化到系统托盘，支持右键菜单暂停/恢复快捷键。
- **智能防冲突**：在录制新按键时自动暂停现有快捷键，避免误触。

## 📖 使用说明 (Usage)

1. **添加规则**：点击 "添加规则" (Add Rule) 打开编辑窗口。
2. **设置触发键**：点击 "捕获" (Capture) 按钮并按下您想使用的按键（支持组合键）。
3. **添加动作**：
   - **Run**: 运行程序 (例如 `notepad.exe`)。
   - **URL**: 打开网页 (例如 `https://www.bilibili.com`)。
   - **CMD**: 执行命令行 (例如 `ipconfig`)，窗口会保持打开以便查看结果。
   - **Send**: 发送模拟按键文本。
4. **保存**：点击保存，配置将写入 `config.json` 并立即生效。
5. **暂停/恢复**：右键点击任务栏右下角的托盘图标，选择 "暂停快捷键" 即可临时禁用所有功能。

## 📂 文件结构 (File Structure)

- `config.json`: 配置文件 (首次运行后自动生成)。
- `README.md`: 项目说明文档。
